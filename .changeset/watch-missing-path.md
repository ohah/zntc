dev 중 모듈이 잠시 사라졌다 돌아오면 다시 반영되도록 고쳤습니다 (#4683).

`git checkout` / 브랜치 전환 / 파일 이동처럼 모듈이 잠깐 사라지면 빌드가 한 번 실패하는데, 그 뒤로는 파일이 돌아와도 **영영 반영되지 않았습니다**. dev 서버를 재시작해야 풀렸습니다.

파일 감시자가 아직 없는 경로를 **조용히 버리던** 것이 원인이었습니다. 호출하는 쪽은 등록됐다고 알지만 실제 감시는 없는 상태가 남고, 이후 재등록 시도는 "이미 등록됨"에 막혀 되살아나지 않았습니다. 이제 없는 경로도 목록에 남겨 두고, 파일이 생기는 즉시 감시를 겁니다.
