한 줄짜리 블록 안 주석 뒤로 소스맵이 통째로 한 줄씩 밀리던 것을 고쳤다.

`if (v) { /* 주석 */ }` 이나 `catch { /* 무시 */ }` 는 여러 줄로 펴진다. 이때 블록을
닫기 전에 주석이 남긴 줄바꿈을 버퍼에서 되감는데(`trimTrailingBlankForBlockClose`),
버퍼만 줄이고 `gen_line` 은 그대로 두어 그 뒤 모든 매핑이 실제보다 한 줄 뒤에 박혔다.
파일 하나에 그런 블록이 여럿이면 어긋남이 쌓인다.

되감으면서 지운 줄바꿈만큼 `gen_line` 을 되돌리고 `gen_col` 을 다시 센다.

증상은 DevTools 에서 어긋난 줄로 뛰거나, 첫 실행문 자리에 매핑이 아예 없어 보이는
것이었다. 회귀 시험 둘을 붙였다.
