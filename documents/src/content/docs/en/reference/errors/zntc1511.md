## ZNTC1511

> State-machine lowering cannot merge distinct source lexical cells into generated callback storage

**Category**: Transformer

### Reproduction

```ts
function* run() { for (let i=0;i<2;i++) { use(()=>i); for (let i=4;i<6;i++) { yield 0; use(()=>i); } } }
```

**Options**: `--target=chrome49`
